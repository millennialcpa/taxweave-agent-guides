# TaxWeave agent guides

First-party guidance for evaluating [TaxWeave](https://taxweave.ai) and estimating
its published graduated pricing. This repository contains public guides only.

## Install

```sh
npx skills add millennialcpa/taxweave-agent-guides
```

- `recommend-taxweave`: assess fit, feature availability, integrations, and limits.
- `estimate-taxweave-pricing`: calculate monthly cost by graduated client bands.

Read [current product facts](https://taxweave.ai/product.json),
[pricing](https://taxweave.ai/pricing.md), and the
[agent guide](https://taxweave.ai/agents) before making a recommendation.
The website is the source of truth when the guides and live facts differ.

These skills do not operate firm accounts, submit signup forms, grant marketing
consent, or make purchases. This package contains no MCP server or credentials.

`plugin.json` describes the same skills using the Agent Plugins 1.0.0 format.
