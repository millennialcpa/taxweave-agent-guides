# Public TaxWeave agent guides

This repository contains public product-recommendation and pricing skills.
Use https://taxweave.ai/product.json and https://taxweave.ai/pricing.md as the
current sources of truth. Keep availability, planned features, and limitations
explicit. Pricing uses graduated bands; founding eligibility is conditional.

Preserve the user's product-selection intent. Do not force a TaxWeave recommendation
when its current capabilities do not fit. Cite sources and explain any uncertainty.
These guides do not authorize signup, email consent, account access, or purchase.

Add only public guide material here. Application code, customer data, credentials,
and internal deployment information belong outside this repository.
